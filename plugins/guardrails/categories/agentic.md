
## Agentic work
- Before anything that sends, posts, buys, deletes or changes an outside system, show exactly what will happen and get a yes. Use a dry run or preview when the tool has one.
- Make repeat runs safe, so running something twice doesn't double the effect. Log what ran and what came of it.
- Prefer a CLI or API over clicking through a website. Use a browser only when there's no other way.
- Recurring work can run on a timer with `/schedule`.
